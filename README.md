# c4d-skills

Набор скиллов Claude Code для пайплайна Cinema 4D: планирование, лейаут, анимация, свет/материалы/рендер и подготовка ассетов.

## Состав

| Скилл | Роль |
|---|---|
| `/c4d-plan` | Планировщик-режиссура: допрашивает по идее, пишет план и промты проходов. C4D не нужна. |
| `/c4d-asset` | Ассеты: библиотека `~/c4d-assets`, прокси и импорт FBX/OBJ/Mixamo, контракт `CHAR_biped_v1`. |
| `/c4d-layout` | Лейаут: строит сцену по `scene.json` — прокси, окружение, камеры, fps. |
| `/c4d-animator` | Анимация: ключи на нулевых контроллерах, камеры по шотам, контактные листы. |
| `/c4d-look` | Свет, материалы, рендер-сеттинги, финальная критика кадра. |
| `c4d-core` | Общая база: preflight, надёжность MCP-тулов, прелюдия, соглашения об именах. Роли читают её сами. |

## Установка на новой машине

```bash
git clone <url-репозитория> ~/c4d-skills
~/c4d-skills/install.sh
```

Скрипт делает симлинки из `~/.claude/skills/` на папки репозитория, поэтому `git pull` сразу обновляет скиллы.

## Требования

- `/c4d-plan` работает где угодно — Cinema 4D не нужна.
- Остальным ролям нужен Cinema 4D 2024 с MCP-плагином (мост на порту 5555) и MCP-сервер `cinema4d`, подключённый к Claude Code.

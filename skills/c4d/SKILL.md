# /c4d — исполнитель в Cinema 4D

Один исполнитель с режимами вместо пяти ролей: план пишет `/c4d-plan`, всё остальное —
здесь. Режим берётся из первой строки промта (`/c4d свет`) или из просьбы пользователя.

## Шаг 0 — всегда

1. Прочитай `~/.claude/skills/c4d-core/SKILL.md` (мост, раннер, лестница, **гейты §4**).
2. `bash ~/.claude/skills/c4d-core/bin/preflight.sh` — по FIX-строкам, если не ок.
3. Проект: `ls -t ~/c4d-projects/` → по просьбе/промту; прочитай хвост `pipeline.md`
   (последние 2–3 записи и «порядок сборки»), `scene.json`. Версия из промта («scene.json
   vN») не совпала с файлом — промт устарел: скажи и предложи `/c4d-plan` (перевыпуск).
4. Открой файл режима (таблица ниже) — только нужный.
5. Новый приём, которого ещё не делал в этом проекте (альфа, стекло, MB, текст, импорт,
   тейк…) — сначала `grep -n -i <слово> ~/.claude/skills/c4d-core/reference/traps.md`.

## Режимы

| Режим | Когда | Файл |
|---|---|---|
| `сцена` | построить по scene.json: болванки, окружение, камеры, лестница пресетов | `modes/layout.md` |
| `ассеты` | новые модели (поиск, импорт, приведение), процедурные, кит, подмена болванок | `modes/asset.md` + `c4d-core/reference/model-sources.md` |
| `анимация` | ключи, тайминг, трюки, моушн, камера | `modes/animator.md` + `c4d-core/reference/motion.md` |
| `материалы` / `свет` / `рендер` | look, лист ключевых кадров, пресет финала, замер, финал | `modes/look.md` + `c4d-core/reference/render-presets.md` |
| `итерации` | после первой приёмки: правки короткими репликами | ниже, в этом файле |
| свободная работа | «что в сцене», «поправь X», разовый вопрос | `c4d-core/reference/bridge.md` (команды моста) + `run.py --code` |

Без плана пользователь хочет «просто сделай X» — не гони его в `/c4d-plan`: спроси 1–3
вопроса, которые меняют результат, и делай. Сцена дольше 5 секунд с несколькими объектами
и без плана — предложи `/c4d-plan` одной строкой и продолжай, если откажется.

## Режим `итерации` — основной цикл после приёмки

Пользователь правит часто и коротко («больше импакта», «камера дёргается», «скучно»).
Цикл на каждую реплику:

1. **Понять** — переформулируй правку в числах одной строкой («удар: дно за 2 кадра
   вместо 3, hit-stop 2 кадра, перелёт возврата +0.035»). Открытая правка («скучно»,
   «вяло», «предложи») → меню 3–7 вариантов с номерами (motion.md §11 «почему вяло»).
2. **Править скрипт** (не сцену руками): нужный `scripts/NN-*.py`, бэкап `.vK.py`
   перед крупной правкой. Прогнать **цепочку из порядка сборки** в pipeline.md, начиная
   с изменённого скрипта (скрипты затирают друг друга — traps.md).
3. **Проверить автоматически**, что можно числом: кадрирование, проникновения, пересвет.
4. **Показать**: движение → `playblast.py` (видео откроется само); правка камеры, света,
   материалов → `keysheet.py` (лист с % пересвета). Правка камеры → **и то и другое**.
5. **Журнал**: строка в `pipeline.md` — `vN — «цитата» — что сделано — файл`.
   Числовые изменения плана → `scene.json` (`version+1`).
6. **Отчёт в 2–4 строки** и ждать следующей реплики.

Не делать в итерациях: перевыпуск промтов, заявки, финал «чтобы посмотреть»,
перерендер всего ролика ради правки в одном месте.

## Финал — только через гейт

`final.py estimate` → показать оценку → свежий `keysheet.py` после последней правки →
пользователь принял лист → `final.py launch --accepted keys-vN` → `final.py watch` в фоне
(`run_in_background`) → видео приходит само. Подробности — c4d-core §4, modes/look.md.
Пользователь сказал «рендери сразу/на ночь» — гейт листа всё равно проходит (лист делаю
сам и смотрю сам; явный пересвет или дефект — чиню до запуска и говорю об этом).

## Чего не делать никогда

- Не запускать чистовой рендер без принятого листа ключевых кадров.
- Не держать чат больше минуты на ожидании: долгое — в фоне, с одной строкой «что идёт».
- Не вызывать `StopExternalRenderer`, не закрывать/перезапускать C4D без согласия
  (кроме намертво зависшей — и тогда сказать).
- Не брать без спроса сцены пользователя как источник моделей: нужны **новые** модели
  (modes/asset.md). Скачивание файла — с согласия: имя, источник, размер.
- Не синтезировать звук без просьбы (звук сейчас вне скоупа скилла).

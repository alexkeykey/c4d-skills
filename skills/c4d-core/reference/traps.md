# Ловушки C4D 2024 и моста — найдено в работе

Каждая строка стоила итерации или часа. Перед новым приёмом греп сюда по ключевому
слову (`grep -n -i "выдерж\|альф\|MB" traps.md`). Нашёл новую — допиши строкой сюда
(симптом → причина → лечение), а не только в pipeline.md проекта.

## Мост и процесс C4D

- **Лимит 60 с главного потока на вызов** (`timed out after 60.0s on C4D main thread`).
  Клиентский таймаут его не лечит. Таймаут не останавливает работу в C4D: следующий
  вызов встаёт в очередь → `run.py --wait`, потом дробить. Рендеры через мост — пачками
  с бюджетом ≤ 45 с (frames_job делает сам), Physical — по кадру.
- **exec_python выключен после перезагрузки мака** (env `C4D_MCP_ENABLE_EXEC_PYTHON`
  слетает) → `bin/restart.sh`: `launchctl setenv … 1` + перезапуск C4D.
- **C4D висит намертво** (ping молчит, CPU ~0): модальное окно (диалог сохранения,
  восстановление, лицензия) или дедлок → сначала попросить пользователя глянуть на экран;
  нет модалки — `restart.sh --force`. После суток работы порт 18710 закрывается сам — рестарт.
- **`c4d.documents.StopExternalRenderer()` через мост вешает C4D.** Остановить Picture
  Viewer просит пользователя (Esc/стоп в PV), сам — никогда.
- **`KillDocument` активного документа изнутри вызова моста вешает C4D** (ответа нет, CPU ~0).
  Закрывать документы — пользователь руками или сначала сделать активным другой документ
  отдельным вызовом; проще не закрывать вовсе.
- **`ShowBitmap` / `EventAdd()` на каждом кадре пачки роняют C4D** (crash в
  `c4d_viewport_render.xlib`). `render_to(show=False)` по умолчанию, EventAdd — один раз в конце.
- **`RenderDocument` в MultipassBitmap с альфой в 1080p уронил C4D.** Альфу рендерить
  асинхронным финалом в PV (`final.py launch --alpha`), не через RenderDocument.
- **Несколько открытых документов**: скрипт без явной активации правит активный, а это
  может быть чужая сцена (один раз сцену сохранили под чужим именем). Раннер активирует
  `<slug>.c4d` сам; в разовом коде — проверять `doc.GetDocumentName()`.
- **Ответ тяжёлых команд — сотни МБ одной строкой** (render, get_mesh) — читать до `\n`
  циклом (клиент делает), большие — `--out file.json`.
- **В JOB-данных питоновские литералы**: писать `repr()`, не json (`true`/`false` не
  питон). Раннер `--job` делает repr сам.
- **`open()` внутри C4D читает в ASCII** — кириллица в файле → UnicodeDecodeError. scene.json
  раннер передаёт словарём `SCENE`; свои файлы — `open(p, encoding="utf-8")`.
- **Viewport renderer для плейбласта не годится**: рисует сетку, HUD, гизмо. Только
  RenderDocument через пресет.

## Время, ключи, анимация

- **`BaseTime(секунды)` округляет** — ключи ставить `BaseTime(кадр, fps)`; полукадр —
  `BaseTime(int(f*1000), fps*1000)`.
- **Снятие трека оставляет параметр «застрявшим»** со значением последнего прогона —
  исходную позу задавать явно в начале скрипта (буквы лежали внутри кейкапа).
- **Удаление блока из скрипта материала/света не возвращает значение в сцене** — то же:
  исходные значения явно.
- **Перезапекание одного скрипта сбрасывает правки другого** (02-anim вернул ступеньки
  09d в LINEAR) → фиксированный порядок сборки в pipeline.md, цепочку гонять целиком.
- **Ключ видимости LONG-параметра**: `SetValue` игнорируется, нужен `SetGeData`
  (prelude.key_vis делает).
- **MB + мгновенная смена видимости** → «призрак» обоих состояний: ступенька на f−0.5
  (`key_vis(..., mb=True)`). Видна на кадр позже, если ключ на кадре удара.
- **Physical не рендерит частичную видимость Display-тега** (скачок 1→0 вместо
  затухания) → гасить альфой/прозрачностью материала.
- **Свой Display-тег у ребёнка перекрывает групповой** — гасить ребёнка его же ключом.
- **Дети с видимостью «вкл» вместо «по умолчанию» не прячутся вместе с родителем.**
- **Анимация/MoGraph корректны только после прогона пассов**: `doc.SetTime` +
  `ExecutePasses(None, True, True, True, BUILDFLAGS_NONE)`; MoGraph — шагать с 0, не прыгать.
- **HPB у элевации ~90°** (камера сверху, объекты «к камере») крутится вихрем —
  замораживать ориентацию у полюса.
- **Protection-тег на камере с Target-тегом блокирует и поворот** — защищать только P/S.
  Навигация во вьюпорте двигает активную сценовую камеру — работать с редакторской.
- **Чужие риги с Protection-тегами** (минифигурки): каналы суставов заблокированы
  (Shoulder/Hip — только rp, Waist/Neck — только rh). Сначала прочитать теги и знаки
  каналов скриптом, наклон корпуса — через корень с компенсацией бедра.
- **Рендер берёт текущее время документа**: пользователь крутит таймлайн — кадр уезжает.
  render_to ставит время сам.

## Камера и motion blur

- **Physical берёт ВЫДЕРЖКУ камеры, не угол затвора** (угол — только Movie Camera).
  Дефолт 1/30 = смаз на весь кадр. Ставить `CAMERAOBJECT_SHUTTER_SPEED_VALUE` = 1/60;
  `CAMERAOBJECT_SHUTTER_SPEED_PRESET_1_60` значение НЕ меняет. Проверять чтением значения.
- **MB в черновиках не виден** (он только в RS_final) — предупреждать пользователя, что
  на плейбласте его нет; оценивать MB на листе ключевых кадров с `--mb`.

## Свет

- **`LIGHT_TEMPERATURE` — булев флаг**, кельвины — `LIGHT_TEMPERATURE_MAIN`; перепутал —
  красный кадр.
- **Затухание Inverse Square Clamped обрезает свет за опорной дистанцией.**
- **Исключение группы из света не действует на детей** — исключать поштучно
  (`LIGHT_EXCLUSION_LIST`).
- **Тень под прыжком заливают key и rim** — подиум/пол исключить из них, тень даёт верхний area.
- **Area-свет Physical ярче с ростом площади**; Specular 1.0 у пластика + большие софтбоксы =
  белые верхние грани → Specular ~0.25–0.45, проверять clipcheck.
- **Контровые на прозрачном корпусе** = белый молочный корпус → исключить корпус из rim.
- **Все источники — с тенями** (решение пользователя). Fill/rim без теней дают «плавающие» объекты.
- **В не-Main тейке параметры света заблокированы**, а переключение тейка меняет активный
  RenderData (25 мин бисекции «почему нет теней»). Авторить только в Main; тейки — в конце.
- **Видеопосты с выключенным флагом активности не применяются**; Physical без своего
  видеопоста не сэмплирует. Клонирование RenderData тащит чужие посты (Magic Bullet Looks).
- **Glow-канал материала Physical не рисует**; Glow-постэффект светит по метке, даже пока
  объект тёмный — включать метку на нужном кадре.

## Материалы и геометрия

- **Стекло**: матовое стекло (blurry refraction) = ×11 времени кадра (212 с против 19 с);
  стекло в целом = шум и молочные засветы — пользователь отвергал. Если нужно — roughness 0,
  ограничить глубину трассировки, проверять на листе ключевых кадров до финала.
- **Materials с GGX-слоями при выключенных отражениях в Standard рендерятся чёрными**
  (RS_draft держит отражения вкл).
- **Текстуры кешируются**: перерисовал файл — новое имя файла, иначе C4D покажет старое.
- **Xgradient**: START/END по умолчанию (±100,0,0) — задавать все оси; `SLA_GRADIENT_CYCLE=1`
  по умолчанию → полосы; у Standard-альфы `MATERIAL_ALPHA_IMAGEALPHA=1` → без альфа-канала
  непрозрачно.
- **Extrude**: `EXTRUDEOBJECT_EXTRUSIONOFFSET` по умолчанию 100 × масштаб → толстый брусок.
- **`MCOMMAND_JOIN` в 2024 молча оставляет первый объект** — объединять своим кодом.
- **Пересборка полигонального объекта**: не копировать Tpoint/Tpolygon (VariableTag) со
  старого — вернут старую геометрию.
- **CAD-сборки спроектированы вплотную**: проверять ГЛУБИНУ проникновения (допуск 0.01),
  а не факт пересечения (`lib_solids.py`).
- **Bevel на чужой геометрии даёт артефакты** — пользователь отверг фаски.
- **LDraw-материалы приходят лаком** — пресет ABS (GGX 0.30, отражение/блик ~0.45).

- **`asset_merge()` из assetlib грузит без материалов** — для скачанных моделей
  `import_model()` (model-sources.md §3). glTF со сжатием Draco/meshopt/KTX2 C4D 2024
  не читает — конвертация через Blender (на 2026-10-09 Blender НЕ установлен —
  установка = скачивание, с согласия).
- **`RENDERSETTING_AO_*` в 2024 нет** (старые скрипты молча пропускали под hasattr) —
  AO это `VPAMBIENTOCCLUSION_*`; качество AO в Physical — `VP_XMB_RAYTRACING_SAMPLES_BLURRY_AO`.
- **GI «Irradiance Cache» в 2024 = `GI_SETUP_METHOD_IC2`**, качество — `GI_SETUP_DATA_IC2_QUALITY`
  (`GI_SETUP_DATA_IR_DENSITY_QUALITY` — legacy IC).

## Текст и шрифты

- **`GeClipMap.GetFontDescription` отвечает True на любое имя** — проверять метриками.
- **Нет глифов (кириллица в DIN Alternate)** → пустой кадр 1.9 КБ. Проверять размер PNG.
- **`PRIM_TEXT_HEIGHT` не применяется** — масштабировать по габариту.

- **`key(o, "rh|rp|rb", f, v)` принимает ГРАДУСЫ** (prelude сам делает radians). Передал `math.radians(22)` — поворот 0.38°, «хлопушка не открывается» (role-objects, 2026-10-11).

## Вывод, альфа, файлы

- **Прозрачный фон**: небу выключить Seen by Camera И Seen by Transparency/Refraction —
  иначе небо видно сквозь полупрозрачное. PV показывает straight-альфу без прозрачности —
  проверять наложением на цвет (`final.py watch --bg`).
- **Picture Viewer рендерит копию сцены на момент запуска** — правки после старта в прогон
  не попадут; правка во время прогона = дорендер затронутого диапазона потом.
- **H.264 с B-кадрами дёргается в After Effects** — ошибочно диагностировали «дёрганую
  анимацию». Для монтажа — ProRes или `-bf 0` (assemble делает).
- **macOS нечувствительна к регистру**: `FINAL-4k` перезаписал `final-4k`. Имена различать
  не регистром.
- **AO с `VP_XMB_RAYTRACING_SAMPLES_BLURRY_AO=1` даёт зерно** — нужно 4.
- **GI IR мерцает в анимации**; QMC очень медленный; для анимации — QMC + Light Mapping
  (или без GI + AO — обычно хватает, 3–4 с/кадр в 1080p).

## Шелл

- zsh: `rm -f glob*` без совпадений рвёт цепочку `&&`; в цикле строка не делится на слова;
  `while read` съедается внутренней командой → `read -u 3`.
- Ассеты из интернета: Sketchfab без логина не скачать; скачивание любого файла —
  только с согласия пользователя (имя, источник, размер).

- **Стекло (Standard) + AO = чернота внутри.** Закрытая прозрачная форма (колба, бутылка) в RS с Ambient Occlusion: AO считает стекло непрозрачным, всё внутри уходит в полную тень — жидкость не видна даже при 100 % прозрачности. Лечится Compositing-тегом на стекле: `COMPOSITINGTAG_SEENBYAO`, `CASTAO`, `CASTSHADOW` = False (role-objects/06-flask.py, 2026-10-11).
- **Масштаб 0.001 по одной оси ≠ невидимость.** Слой-цилиндр с `sy ≈ 0` рендерится плоским диском (крышки). Чтобы «нет до появления» — гасить и `sx/sz` ступенькой.

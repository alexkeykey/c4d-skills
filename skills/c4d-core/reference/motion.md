# Движение: справочник аниматора

Общая база по движению для режима анимации `/c4d`, для `/c4d-plan` и лейаута: персонажи,
предметы, продукт, типографика, камера. Цикл бега бипеда, знаки `rb`, выбор оси маха,
застрявшие параметры — в `c4d/modes/animator.md`, здесь не повторяются.

Условности файла:
- кадры даны как **24 [30]** — первое число для 24 fps, в скобках для 30. Пересчёт: `кадры30 = кадры24 × 1.25`, `кадры = мс × fps / 1000`;
- единицы — сантиметры C4D, `g = 981 см/с²` = **1.703 см/кадр²** при 24, **1.090** при 30;
- `key(obj, ch, frame, val, interp)` — из прелюдии c4d-core; `bake(o, ch, f0, f1, fn)` — тоже оттуда; код ниже — чистый python + `math`/`random` (без `import os`, `eval(`, `exec(`);
- «ease-in» = разгон (медленно → быстро), «ease-out» = торможение (быстро → медленно). В C4D сплайн-ключ с автотангенсами ≈ ease-in-out cubic.

## 0. Как пользоваться

### Чек-лист «перед ключами» (5 минут, письменно в `pipeline.md`)

1. **Что движется** — персонаж / твёрдый предмет / мягкий предмет / продукт / текст / камера.
2. **Характер** — одно слово из §4 (тяжёлый, лёгкий, упругий, механический, живой, игривый, агрессивный, вялый). Если два — какой ведёт.
3. **Вес и масштаб** — реальный размер в см и размер, каким он должен **читаться**. Не совпадают → масштабируй время (§2.4).
4. **Ведущее/ведомое** — что начинает движение, что тянется следом (§5). Порядок остановки: от корня к кончику.
5. **Принципы** — выпиши 3–5 из §1, которые будут видны. Не «все 12», а те, что продают этот шот.
6. **Тайминг** — длина шота в кадрах, кадры ключевых поз, доли музыки (§8.6), кадр главного акцента.
7. **Кривые** — для каждого сегмента имя функции из §3 (`out_expo`, `spring ζ=0.4 f=3`…).
8. **Проверка** — что считаешь численно (скорости, перелёт, контакт с полом) и какие кадры рендеришь.

Шаблон записи:

```markdown
### motion-brief: <объект>, шот <id>
Характер: тяжёлый (ведёт), вторичное — упругое
Масштаб: 4 см, читается как 180 см → время ×6.7 (§2.4)
Ведущее: CTRL → root → голова (+2 кадра) → антенна (spring ζ0.3 f4)
Принципы: anticipation, follow-through, slow-in в контакт без ease, hit-stop 3 кадра
Ключевые позы: 0 стойка, 10 замах, 14 контакт (=доля 2), 17–19 hit-stop, 30 оседание
Кривые: замах in_out_pow(3); удар in_pow(2)→linear; оседание spring ζ0.5 f2.5
Проверка: перелёт ≤5%, нет скорости >40 см/кадр без блюра, рендер 10/14/18/30
```

### Порядок работы (pose-to-pose)

1. **Блокинг в step** — только экстремумы, `interp="step"`. Смотри позы и паузы, без интерполяции.
2. **Брейкдауны** — промежуточная поза между экстремумами решает дугу и спейсинг (обычно на 1/3 ближе к одному из ключей, не посередине).
3. **Сплайн/запекание** — переводишь в кривые; для всего, где важна форма кривой, — покадровое запекание функцией из §3 с `linear`.
4. **Оверлап и вторичное** — сдвиги фаз, пружины (§5).
5. **Полировка** — дуги, moving holds, микропаузы, проверка §11.

Правило: **меняй тайминг на этапе блокинга**, пока ключей мало. Каждый слой сверху (оверлап, вторичное) переделывается при сдвиге базового тайминга.

## 1. Двенадцать принципов (Thomas & Johnston) в 3D

### 1.1 Сжатие и растяжение (squash & stretch)
Суть: форма деформируется от скорости и удара, **объём сохраняется**. Даёт массу и гибкость.
Ошибка: объект «надувается» (растянули Y, не сжали XZ); сжатие от центра — объект проваливается в пол; сквош у твёрдого (сейф, логотип-металл) — читается как резина.

В C4D:
- деформируй **отдельный нуль-сквош** между CTRL и геометрией, пивот — в точке контакта (низ объекта), иначе при сжатии он уйдёт под пол;
- объём: `sx = sz = 1/sqrt(sy)`;
- растяжение — **вдоль вектора скорости**: нуль-ориентир поворачиваешь по направлению движения, внутри него масштаб по одной оси;
- дозировка:

| Стиль | Растяжение в полёте | Сжатие в контакте | Длительность сжатия |
|---|---|---|---|
| реализм (плоть, мяч) | 1.03–1.08 | 0.92–0.97 | 1 кадр [1–2] |
| стилизация | 1.15–1.3 | 0.75–0.85 | 1–2 [2] |
| мульт | 1.4–2.0 | 0.5–0.7 | 2 [2–3] |
| твёрдое тело | 1.0 | 1.0 — вместо сквоша отдача и тряска | — |

- Растяжение только на кадрах **максимальной скорости**; на апексе и в паузе форма = 1.0. На кадре контакта — сжатие, через 2–3 кадра [3–4] — возврат с перелётом в растяжение 1.02–1.05.

### 1.2 Подготовка (anticipation)
Суть: короткое движение **против** главного перед ним — копит энергию и предупреждает зрителя.
Ошибка: нет подготовки — старт как рубильник; подготовка длиннее действия в 4+ раза — движение «телеграфирует» и вязнет.

В C4D:
- амплитуда 10–30% главного движения, противоположный знак;
- длительность: подготовка : действие ≈ **2:1–3:1** для крупных действий, 1:1 для мелких;

| Действие | Подготовка | Действие |
|---|---|---|
| мелкое (кивок, жест) | 3–4 [4–5] | 3–4 [4–5] |
| среднее (прыжок, старт) | 6–8 [8–10] | 3–4 [4–5] |
| большое (замах молотом) | 12–20 [15–25] | 3–6 [4–8] |
| агрессивное (удар) | 2–4 [3–5], резко | 1–2 [2–3] |

- кривая подготовки — `in_out_pow(t,2..3)`, в крайней точке **пауза 1–3 кадра**, затем действие с `in_pow` или `out_expo` (§3).

### 1.3 Подача (staging)
Суть: одна идея за раз, читаемо силуэтом и с той точки, где стоит камера.
Ошибка: главное действие происходит одновременно с тремя второстепенными; рука перекрывает лицо; движение идёт на камеру (не видно по силуэту).

В C4D:
- проверка силуэтом: рендер с чёрным материалом на белом фоне (или альфа) — действие должно читаться;
- главное движение — **поперёк** оси камеры (в плоскости кадра), не к/от объектива;
- во время акцента вторичные элементы затихают (амплитуда ×0.3) — контраст движения и покоя;
- зритель смотрит туда, где **что-то начало двигаться** последним. Не стартуй два движения на одном кадре в разных частях кадра.

### 1.4 Прямое действие и поза-к-позе
Суть: позы-ключи с промежутками (контроль тайминга) против покадрового «потока» (органика, хаос).
Ошибка: поза-к-позе для огня/воды/осколков — механично; прямое действие для персонажа — уплывает по таймингу.

В C4D: персонаж, продукт, текст — поза-к-позе (блокинг step → сплайн). Огонь, дым, ткань, осколки, толпа — «прямое» = формула или симуляция, запечённая покадрово (§3, §5, §6.6). Гибрид: позы корня ключами, вторичное процедурно поверх.

### 1.5 Проводка и перекрытие (follow-through & overlapping action)
Суть: части тела стартуют и останавливаются в разное время; свободные части продолжают движение после остановки корня.
Ошибка: всё стартует и замирает на одном кадре — «картонка на шарнире»; или все звенья качаются бесконечно — «желе».

В C4D:
- задержка по цепочке **1–2 кадра [1–3] на звено** (корпус → плечо → локоть → кисть; таз → корпус → голова);
- амплитуда растёт к кончику ×1.2–1.5 на звено, затем затухание;
- остановка: корень встаёт, кончик проходит дальше на 5–15% и возвращается за 4–8 [5–10] кадров;
- «перелом суставов» (successive breaking of joints, Williams): при взмахе рукой кисть **отстаёт** от предплечья и ломается в обратную сторону, затем догоняет;
- реализация: та же кривая со сдвигом фазы `val(f - k*lag)` или пружина §3.4/§5.

### 1.6 Замедление на концах (slow in / slow out)
Суть: разгон и торможение — масса не мгновенно меняет скорость. Это **спейсинг**: кадры гуще у крайних поз.
Ошибка: ease-in-out на всём подряд — всё «плавает» одинаково; ease в контакт с полом — объект тормозит перед ударом, как будто его ставят рукой.

В C4D:
- падение/удар: **ease-in (разгон) и обрыв** — последний интервал перед контактом самый длинный, ключ контакта `linear`;
- появление (UI, текст, продукт входит в кадр): ease-out (`out_quint`, `out_expo`);
- уход из кадра: ease-in, длительность 0.6–0.8 от входа;
- переход поза→поза у персонажа: асимметричный ease — уход из позы быстрее, приход медленнее (`cubic_bezier(0.3,0,0.1,1)`);
- автотангенсы C4D дают перелёт между близкими ключами → для формы кривой запекай (§3.6).

### 1.7 Дуги (arcs)
Суть: живые объекты движутся по дугам (суставы вращаются), механика — по прямым.
Ошибка: голова/рука едет по прямой из позы в позу; дуга «ломается» на ключе (резкая смена направления); путь зигзагом из-за неравномерных брейкдаунов.

В C4D:
- вращение на пивоте даёт дугу автоматически — двигай поворотом родителя, а не позицией кончика;
- если ключуешь позицию — добавь смещение по второй оси: `y += sag*sin(pi*u)`, `sag = 5–15%` хорды;
- поворот головы: дуга **вниз** на середине (голова «ныряет» на 5–10°, на 1/2 пути), иначе выглядит как турель;
- проверка: напечатай мировую позицию кончика по кадрам — вторые разности не должны менять знак скачком (§11.9).

### 1.8 Вторичное действие (secondary action)
Суть: действие, которое **поддерживает** основное (взмах хвостом при прыжке, поправить очки после удара), не конкурируя с ним.
Ошибка: вторичное громче основного; стартует одновременно и отвлекает.

В C4D: амплитуда 20–40% основного, сдвиг во времени +2–6 кадров [3–8] после начала основного или в его холде. Одно вторичное на действие.

### 1.9 Тайминг (timing)
Суть: число кадров на действие = вес, характер, эмоция. Одно и то же движение за 6 и за 18 кадров — разные персонажи.
Ошибка: всё по 24 кадра «на всякий случай»; одинаковые длительности у разных по массе объектов.

В C4D: таблицы §2. Правило размера: время ∝ `sqrt(размер)`. Анимация «на единицах» (ключ/запекание на каждый кадр) — норма 3D; «на двойках» (step через кадр) — осознанный стиль (аниме, Spider-Verse), включается запеканием `step=2` + `interp="step"`.

### 1.10 Преувеличение (exaggeration)
Суть: усилить суть позы/тайминга, чтобы читалось на экране. Реалистичная копия выглядит вялой.
Ошибка: преувеличено всё одинаково (мульт); или ничего — «видео с камеры наблюдения».

В C4D: экстремумы поз +10–30% к «правильным», паузы длиннее (+2–4 кадра), контраст скоростей сильнее (быстрое — быстрее). Преувеличивай **одну** ось характера, не все.

### 1.11 Твёрдый рисунок → твёрдая поза
Суть: объём, баланс, вес на опорной ноге, линия действия.
Ошибка: «близнецы» (twinning) — обе руки/ноги симметричны и синхронны; центр масс вне площади опоры без причины.

В C4D: центр масс над опорой в статике (проекция ЦМ ≈ на линии стоп); асимметрия левых/правых каналов: амплитуды ±10–20%, фазы ±1–2 кадра; линия действия — одна кривая через корпус и голову (С- или S-образная), проверяй с камеры.

### 1.12 Обаяние (appeal)
Суть: зрителю хочется смотреть — ясные формы, понятный характер, ритм.
Ошибка: однообразный ритм (всё в одном темпе), шум из мелких движений, неясный силуэт.

В C4D: чередуй быстрое и медленное (§8.3), держи паузы, упрощай: меньше одновременных движений, больше контраста.

### 2.3 Отскоки

Коэффициент восстановления `e` (скорость после / до удара): каждый отскок — высота `×e²`, время полёта `×e`. Полёт после n-го удара: `T_n = 2·e^n·sqrt(2h/g)`.

| Материал | e | Сжатие в контакте | Сколько видимых отскоков |
|---|---|---|---|
| суперболл | 0.85–0.9 | 0.9 | 6–8 |
| резиновый мяч / баскетбол | 0.75–0.8 | 0.8–0.9 | 4–5 |
| теннисный | 0.7 | 0.85 | 3–4 |
| пластик твёрдый | 0.5–0.6 | нет, тряска | 2–3 |
| дерево | 0.4–0.5 | нет | 1–2 |
| металл тяжёлый, камень | 0.1–0.3 | нет | 0–1 + перекат |
| глина, мешок, тело | 0–0.1 | 0.6–0.7 и оседание | 0 |

Тяжесть читается не высотой, а **числом и скоростью затухания** отскоков. Отскок ниже 2–3 см не делай: переходи в перекат/вибрацию 2–4 кадра.

### 2.4 Масштаб и время

Физическое время ∝ `sqrt(размер)`. Два следствия:

- **Игрушка, которая должна читаться как человек** (минифигурка 4 см): реальная физика даст «мелкий быстрый» объект. Растягивай время в `sqrt(H_читается / H_реальный)` = `sqrt(180/4) ≈ 6.7` раза, или используй `g_eff = g · H_реальный / H_читается`. Это то же правило, по которому миниатюры в кино снимают с частотой ×`sqrt(масштаб)`.
- **Гигант** ростом в 3.5 человеческих: все его падения, шаги, качания длиннее в `sqrt(3.5) ≈ 1.87` раза. Ускоришь — станет «человеком в зуме».

Маятник (качели, висящий предмет, рука при ходьбе) длиной L: `T = 2π·sqrt(L/g)`: 10 см → 15 [19] кадров, 50 см → 34 [43], 100 см → 48 [60], 200 см → 68 [85].

### 2.5 Спейсинг

- **Равный спейсинг** = постоянная скорость = механика (конвейер, камера-долли, вращение вентилятора).
- **Деление пополам** (Williams): ease-out к позе — каждый следующий интервал половина предыдущего: 1/2, 1/4, 1/8 пути. 4–5 кадров «половинок» дают мягкую посадку; 2 — жёсткую.
- **Фаворит брейкдауна**: промежуточная поза не на 50%, а на 30–35% или 65–70% пути — определяет, к какой позе движение «прилипает».
- **Скорость за кадр**: при сдвиге > ~10% ширины кадра за кадр глаз видит прыжок, а не движение — нужен блюр или смир (§7.5). Вращение колеса со спицами: шаг за кадр должен быть < половины углового шага спиц (`180/N_спиц` градусов), иначе «эффект дилижанса» — колесо крутится назад.

## 3. Библиотека easing

### 3.1 Функции (вставлять после прелюдии)

`t` — нормированное время 0..1 (кроме `spring`, где t в секундах). Возврат — прогресс; у back/elastic/spring выходит за [0, 1] — так и задумано.

```python
import math  # в песочнице уже есть; строка для запуска вне C4D

def clamp01(t): return 0.0 if t < 0 else (1.0 if t > 1 else t)
def smoothstep(t): t = clamp01(t); return t*t*(3 - 2*t)            # ≈ сплайн C4D
def smootherstep(t): t = clamp01(t); return t*t*t*(t*(6*t - 15) + 10)

# степенные: p=2 quad, 3 cubic, 4 quart, 5 quint
def in_pow(t, p=3): return t**p
def out_pow(t, p=3): return 1 - (1 - t)**p
def in_out_pow(t, p=3):
    return 0.5*(2*t)**p if t < 0.5 else 1 - 0.5*(2 - 2*t)**p

def in_expo(t): return 0.0 if t <= 0 else 2**(10*t - 10)
def out_expo(t): return 1.0 if t >= 1 else 1 - 2**(-10*t)
def in_out_expo(t):
    if t <= 0 or t >= 1: return float(t >= 1)
    return 2**(20*t - 10)/2 if t < 0.5 else (2 - 2**(10 - 20*t))/2

# back: s — сила перелёта (1.70158 = 10%), таблица 3.3
def in_back(t, s=1.70158): return (s + 1)*t**3 - s*t*t
def out_back(t, s=1.70158): u = t - 1; return 1 + (s + 1)*u**3 + s*u*u
def in_out_back(t, s=1.70158):
    s2 = s*1.525
    if t < 0.5: return ((2*t)**2*((s2 + 1)*2*t - s2))/2
    return ((2*t - 2)**2*((s2 + 1)*(2*t - 2) + s2) + 2)/2

# elastic: period — период колебаний в долях длительности (0.3 — классика, перелёт 37%)
def out_elastic(t, period=0.3):
    if t <= 0 or t >= 1: return float(t >= 1)
    return 1 + 2**(-10*t)*math.sin((t - period/4)*2*math.pi/period)

def out_bounce(t):
    n, d = 7.5625, 2.75
    if t < 1/d: return n*t*t
    if t < 2/d: t -= 1.5/d; return n*t*t + 0.75
    if t < 2.5/d: t -= 2.25/d; return n*t*t + 0.9375
    t -= 2.625/d; return n*t*t + 0.984375
def in_bounce(t): return 1 - out_bounce(1 - t)

# CSS/Material cubic-bezier(x1,y1,x2,y2) -> функция f(t)
def cubic_bezier(x1, y1, x2, y2):
    bx = lambda s: 3*x1*s*(1-s)**2 + 3*x2*s*s*(1-s) + s**3
    by = lambda s: 3*y1*s*(1-s)**2 + 3*y2*s*s*(1-s) + s**3
    def f(t):
        lo, hi = 0.0, 1.0
        for _ in range(30):                     # бисекция по x
            m = (lo + hi)/2
            if bx(m) < t: lo = m
            else: hi = m
        return by((lo + hi)/2)
    return f
```

### 3.2 Пружины

```python
def spring(t, zeta=0.5, f=2.0, v0=0.0):
    """Отклик пружины на скачок цели 0->1. t в СЕКУНДАХ, f — собств. частота, Гц.
    zeta<1 — с перелётом, =1 — критическая (быстрее всех без перелёта), >1 — вязкая.
    v0 — начальная скорость в долях пути/с (толчок: v0>0 даёт резкий старт)."""
    w = 2*math.pi*f; x0 = -1.0
    if abs(zeta - 1) < 1e-6:
        return 1 + math.exp(-w*t)*(x0 + (v0 + w*x0)*t)
    if zeta < 1:
        wd = w*math.sqrt(1 - zeta*zeta); b = (v0 + zeta*w*x0)/wd
        return 1 + math.exp(-zeta*w*t)*(x0*math.cos(wd*t) + b*math.sin(wd*t))
    q = math.sqrt(zeta*zeta - 1); r1 = -w*(zeta - q); r2 = -w*(zeta + q)
    c2 = (v0 - r1*x0)/(r2 - r1)
    return 1 + (x0 - c2)*math.exp(r1*t) + c2*math.exp(r2*t)

def spring_follow(x, v, goal, dt, halflife=0.15):
    """Критически задемпфированное преследование цели (Holden). Вызывать каждый кадр,
    dt = 1/fps. Камера/хвост/взгляд догоняет goal без перелёта. Возвращает (x, v).
    При постоянной скорости цели отставание = 1.44*halflife секунд."""
    y = 2*math.log(2)/halflife
    j0 = x - goal; j1 = v + j0*y; e = math.exp(-y*dt)
    return e*(j0 + j1*dt) + goal, e*(v - j1*y*dt)

def spring_step(x, v, goal, dt, zeta=0.4, f=3.0, sub=4):
    """Пружина с перелётом для вторичного (антенна, ухо, плащ). Покадрово, с подшагами."""
    w = 2*math.pi*f; h = dt/sub
    for _ in range(sub):
        a = -2*zeta*w*v - w*w*(x - goal)
        v += a*h; x += v*h
    return x, v
```

### 3.3 Шпаргалка по параметрам

**Back (`s`) → перелёт**: s=0.5 → 1%, 1.0 → 4%, 1.70158 → 10%, 2.5 → 19%, 3.5 → 31%. Пик перелёта на 50–75% длительности.

**Пружина (ζ) → перелёт и время успокоения** (до 2%, при f = 2 Гц):

| ζ | перелёт | успокоение | Характер |
|---|---|---|---|
| 0.2 | 53% | ~1.6 с | желе, мультяшная антенна |
| 0.3 | 37% | 0.9 с | упругое, пружинка |
| 0.4 | 25% | 0.8 с | игривое |
| 0.5 | 16% | 0.64 с | живое, «поп» UI |
| 0.6 | 9.5% | 0.5 с | уверенное |
| 0.7 | 4.6% | 0.48 с | дорогой продукт, серво |
| 0.8 | 1.5% | 0.45 с | почти без перелёта |

| 1.5 | 0 | 0.85 с | вязкое, в масле |

Формулы: перелёт `= exp(−ζπ/sqrt(1−ζ²))`; успокоение ≈ `4/(ζ·2πf)` для ζ<0.8. Время пропорционально `1/f`: f = 1 Гц — всё вдвое дольше, чем в таблице, f = 4 Гц — вдвое быстрее. Из массы/жёсткости: `ω = sqrt(k/m)`, `ζ = c/(2·sqrt(k·m))`. Тяжелее при той же пружине → ниже f, медленнее.

### 3.5 Комбинирование

```python
def chain(*segs):
    """segs: (длит_в_кадрах, v0, v1, ease). Возвращает функцию val(f) от 0."""
    def val(f):
        t0 = 0
        for n, a, b, e in segs:
            if f <= t0 + n: return a + (b - a)*e((f - t0)/float(n))
            t0 += n
        return segs[-1][2]
    return val

def blend(a, b, w):            # плавное сшивание двух функций (окно w 0..1 smoothstep)
    return a + (b - a)*smoothstep(w)
```

Пример — замах-удар-отдача по углу: `chain((10,0,-25,lambda t:in_out_pow(t,3)), (3,-25,80,lambda t:in_pow(t,2)), (12,80,70,lambda t:spring(t*12/24,0.4,2.5)))`. Последний сегмент — пружина в секундах: `t*n/fps`.

### 3.6 Запекание в C4D

В прелюдии есть `bake(o, ch, f0, f1, fn, step=1)`: сносит старый трек канала и ставит `linear`-ключ на каждый кадр со значением `fn(f)`. Адаптер для easing «из A в B»:

```python
def tween(f0, f1, v0, v1, ease):
    n = float(f1 - f0)
    return lambda f: v0 + (v1 - v0)*ease(clamp01((f - f0)/n))

bake("CHAR_x_CTRL", "py", 0, 12, tween(0, 12, 0, 40, out_expo))
bake("CHAR_x_CTRL", "rb", 12, 36, lambda f: 30*spring((f - 12)/FPS, 0.4, 2.5))
```

- Покадрово + `linear` — кривая ровно та, что в формуле; сплайн-автотангенсы между частыми ключами дают перелёты и дрожь.
- `bake` перезаписывает **весь** трек канала: несколько сегментов на одном канале — одной функцией (`chain` из §3.5), а не несколькими вызовами.
- «На двойках»: `step=2` + ключи `step` через `key(..., "step")` своим циклом.
- Лимит времени на скрипт: ~500–1000 ключей за вызов безопасно; больше — режь по объектам.
- Углы, полученные через `atan2`, перед запеканием **разворачивай** (`a += 360` при скачке > 180°), иначе объект крутанётся на полный оборот за кадр.

## 4. Характер и вес

### 4.1 Матрица характеров

Длительность — относительно «нейтрального» действия (=1.0).

| Характер | Длит. | Подготовка | Перелёт | Кривые | Холды | Вторичное |
|---|---|---|---|---|---|---|
| **тяжёлый** | 1.5–2.5 | долгая, медленная, глубокая | 0–3% | долгий `in_pow` разгон, контакт без ease, оседание `spring ζ0.8–1 f1–1.5` | длинные после удара | тряска камеры, пыль, отдача окружения |
| **лёгкий** | 0.5–0.8 | короткая или нет | 5–15% | `out_expo`, `out_back s1`, дрейф | короткие, «парит» в конце | много, мелкое, высокая f |
| **упругий** | 0.7–1.0 | короткая со сквошем | 15–35% | `spring ζ0.3–0.45 f3–5`, `out_back s2–3` | нет, колебание до покоя | сквош-стретч, вибрация |
| **механический** | 0.8–1.2 | нет или «взвод» | 0 или 1-кадровый толчок | `linear`, короткие ease 2–3 кадра, step | точные, полностью неподвижные | нет оверлапа; дрожь двигателя 8–15 Гц мелкая |
| **живой** | 1.0 ±10% | соразмерная | 2–8% | асимметричный ease, дуги | moving hold, дыхание | оверлап 1–3 кадра везде |
| **игривый** | 0.6–0.9 | заметная, со сквошем | 10–20% | `out_back`, `out_elastic`, ритм под долю | короткие паузы-«акценты» | подпрыгивания, стаггер |
| **агрессивный** | 0.4–0.7 | короткая резкая (2–4 кадра) | 5–10% на отдаче | `in_pow` → `out_expo`, прямые пути | hit-stop, резкие стопы | тряска, смир |
| **вялый/усталый** | 1.5–2.0 | почти нет | 0, провисание | длинный ease-out, падение быстрее подъёма | долгие, с проседанием | сильный drag, медленная f 0.5–1 Гц |

Дополнительно:
- **нервный/тревожный**: высокая частота мелких движений (3–6 Гц, ±1–3°), рваный ритм — интервалы 3, 7, 4, 9 кадров, а не ровные; взгляд прыгает быстрее, чем голова поворачивается.
- **дорогой/премиальный (продукт)**: медленно и уверенно, `in_out_pow(t,3..4)` или M3 emphasized, перелёт ≤ 3%, никаких пружин с ζ < 0.6, длинные холды на «hero»-ракурсе.

### 4.2 Как продать вес без размера

1. **Медленный разгон** — тяжёлое долго набирает скорость (подготовка × 2).
2. **Позднее торможение** — останавливается с проскальзыванием/перелётом корпуса вперёд, а не «встаёт на ключ».
3. **Реакция окружения** — пол, камера, соседние предметы вздрагивают (§7.3).
4. **Нет сквоша**, но есть микро-отдача: 1–2 кадра сжатия на 1–3% и долгое оседание.
5. **Частота** — крупное колеблется медленно (f ∝ 1/sqrt(размер)).
6. **Лёгкое** — наоборот: мгновенный старт, долгое торможение (воздух), парение на апексе +2–4 кадра сверх физики.

### 4.3 Лабан: четыре ручки эффорта

Laban Movement Analysis описывает качество движения четырьмя осями. Используй их как ручки, когда характер не укладывается в таблицу 4.1.

| Ось | Полюс A | Полюс B | Чем крутится в C4D |
|---|---|---|---|
| **Вес** (Weight) | сильный — с усилием, давит | лёгкий — без усилия | амплитуда сопротивления (подготовка, отдача), ускорение в конце: сильный ускоряется **в** цель, лёгкий тормозит перед ней |
| **Время** (Time) | внезапный | протяжённый | длительность и крутизна кривой: `in_expo`/`out_expo` и 2–4 кадра против `in_out_pow(2)` и 20+ кадров |
| **Пространство** (Space) | прямое — к одной точке | непрямое — многофокусное | траектория: прямая + взгляд держит цель против дуг, петель, блуждающего взгляда (sag 15–30%, смена направления) |
| **Поток** (Flow) | связанный — контролируемый | свободный — отпущенный | оверлап и демпфирование: связанный — оверлап 0–1 кадр, ζ ≥ 0.8, остановки точные; свободный — оверлап 2–4 кадра, ζ 0.3–0.5, хвосты движений |

Восемь базовых действий (Вес × Время × Пространство):

| Действие | Вес / Время / Пространство | Рецепт |
|---|---|---|
| Удар (punch) | сильный / внезапный / прямое | подг. 4–6, удар 2 кадра `in_pow(2)`, прямая, hit-stop 3 |
| Рубящий (slash) | сильный / внезапный / непрямое | замах по дуге, 3–4 кадра, широкая дуга 90–150°, смир |
| Давить (press) | сильный / протяжённый / прямое | 24–48 кадров, `in_out_pow(2)`, почти линейно, мелкая дрожь усилия 6–10 Гц ±0.5° |
| Выжимать (wring) | сильный / протяжённый / непрямое | скрутка с противовращением частей, 24–36 кадров, оверлап 3–4 |
| Тычок (dab) | лёгкий / внезапный / прямое | 2–3 кадра туда, мгновенный стоп, 3–4 обратно |
| Смахнуть (flick) | лёгкий / внезапный / непрямое | 3–5 кадров по дуге, кончик опережает и хлёстко ломается, `out_back s2` |
| Скольжение (glide) | лёгкий / протяжённый / прямое | постоянная скорость, мягкие концы 6–8 кадров, без вторичного |
| Парение (float) | лёгкий / протяжённый / непрямое | медленные дуги, синусы с разными f по осям (0.2–0.5 Гц), без точек остановки |

Эмоции через ручки: радость = лёгкий + свободный + вверх; гнев = сильный + внезапный + прямой; страх = внезапный + связанный + назад/вниз; грусть = лёгкий-вялый + протяжённый + вниз; уверенность = сильный + протяжённый + прямой.

## 5. Вторичное движение: ткань, плащ, антенны, провода

Правила:
- вторичное **следует за ускорением** родителя, а не за его позицией: при разгоне отклоняется назад, при торможении — вперёд, при постоянной скорости — успокаивается;
- амплитуда ≤ основного движения; затухание до покоя за 0.5–1.5 с — бесконечное качание = желе;
- частота дочернего элемента в 1.5–2 раза выше родительского, иначе резонанс и «болтанка»;
- в холде персонажа вторичное доигрывает 1–2 колебания и замирает — это и продаёт остановку.

Равновесное отклонение висящего предмета при ускорении `a` — `atan(a/g)`: при 500 см/с² ≈ 27°. Это цель для пружины:

```python
def secondary(pos, fps, f=2.0, zeta=0.35, gain=1.0, max_deg=60):
    """pos — позиции родителя по кадрам (см, одна ось). Возвращает углы отклонения, град.
    gain>1 — стилизация, <1 — жёсткий материал. Знак: против ускорения."""
    dt = 1.0/fps; ang = 0.0; vel = 0.0; out = []
    for i in range(len(pos)):
        a = 0.0 if i < 2 else (pos[i] - 2*pos[i-1] + pos[i-2])/(dt*dt)
        goal = -gain*math.degrees(math.atan2(a, 981.0))
        goal = max(-max_deg, min(max_deg, goal))
        ang, vel = spring_step(ang, vel, goal, dt, zeta, f)
        ang = max(-max_deg, min(max_deg, ang))
        out.append(ang)
    return out
```

Цепочка (хвост, плащ из 3–5 звеньев, кабель): звено k получает углы звена k−1 с задержкой 1–2 кадра и множителем 1.1–1.4, или своя `spring_step` с целью = угол предыдущего звена; f растёт к кончику на 20–30% на звено.

| Материал | f, Гц | ζ | gain | Заметки |
|---|---|---|---|---|
| тяжёлая ткань, пальто | 1–1.5 | 0.5–0.6 | 0.7 | медленный drag, мало колебаний |
| плащ, лёгкая ткань | 1.5–2.5 | 0.3–0.4 | 1.0–1.3 | волна по цепочке, задержка 2 кадра/звено |
| флаг, лента | 2–4 | 0.2–0.3 | 1.2 | плюс шум ветра 0.5–1 Гц |
| волосы, хвост | 2–3 | 0.35–0.45 | 1.0 | |
| уши, мягкие придатки | 3–4 | 0.3 | 1.0 | |
| антенна-пружинка | 4–8 | 0.15–0.25 | 1.5 | 3–5 видимых колебаний |
| жёсткая антенна, удочка | 6–12 | 0.1–0.2 | 0.4 | мелкая высокая вибрация |
| провод, кабель | 0.5–1 | 0.6–0.8 | 0.8 | провисание, без колебаний |
| живот, щёки, мягкое тело | 4–6 | 0.4 | 0.5 | 1–2 колебания |

**Коллизия с телом** (плащ не входит в спину):
- ограничь угол со стороны тела: `ang = max(ang, ang_min)`, где `ang_min` — угол касания (замерь в позе); в момент упора обнули скорость пружины в сторону тела (`vel = max(vel, 0)`) — получится «прилип и отлип»;
- базовый отступ ткани от тела 1–3 см; при наклоне корпуса вперёд `ang_min` сдвигай на угол наклона;
- для настоящей ткани — Cloth/Simulation-теги C4D с коллайдером-капсулой вокруг тела (проще, чем меш), кэш симуляции до рендера.

Готовые инструменты C4D: деформер **Jiggle** (мягкие объёмы), эффектор **Delay** в режиме Spring (MoGraph-группы), **Spline Dynamics**/Hair для кабелей и антенн, теги Cloth/Simulation. Для управляемого результата и повторяемости — формула выше и покадровое запекание.

## 6. Механика и акробатика

### 6.1 Центр масс (ЦМ)
- В полёте ЦМ идёт **строго по параболе**, что бы ни делали конечности. Тело вращается **вокруг ЦМ**, не вокруг ступней и не вокруг пивота CTRL.
- ЦМ стоящего человека ≈ 0.55·H (уровень пупка), в группировке ниже и ближе к коленям. У минифигурки — ~0.45·H (тяжёлые ноги).
- В опоре проекция ЦМ лежит над площадью опоры; вышел за неё — объект падает или делает шаг.

Вращение вокруг ЦМ при иерархии CTRL → root (CTRL у ступней):

```python
def ctrl_from_com(cx, cy, theta_deg, hc):
    """ЦМ в (cx, cy), поворот rb = theta, ЦМ на высоте hc над CTRL в локале.
    Знак: rb+ уводит голову в +X (проверено в modes/animator.md) — сверь численно на своём риге."""
    th = math.radians(theta_deg)
    return cx - hc*math.sin(th), cy - hc*math.cos(th)
```

### 6.2 Прыжок
- Скорость отрыва `v0 = sqrt(2·g·h)`; полёт `T = 2·v0/g` (таблица §2.2); горизонтальная скорость в полёте постоянна → `px` в полёте `linear`.
- Фазы: присед 6–10 [8–12] (`in_out_pow(2)`, глубина 15–30% роста ноги) → толчок 3–4 [4–5] (тело вытягивается, stretch 1.05–1.1) → полёт по параболе (группировка к апексу) → контакт → поглощение 3–6 [4–8] → **переразгиб** вверх на 2–5% роста за 4–6 кадров → оседание 6–10 [8–12] (`spring ζ0.5–0.6`).
- Глубина поглощения ∝ высоте падения: 50 см — колени 20–30°, 150 см — присед 60–90° и руки вперёд/вниз.
- На апексе вертикальная скорость ноль: 2–3 кадра почти без смещения по Y — так «висят» в воздухе. Добавить искусственного висения +2–4 кадра → лёгкий/мультяшный.

### 6.3 Сальто
- Угловой момент в полёте постоянен: `ω·I = const`. Группировка уменьшает момент инерции в 2–3 раза → вращение ускоряется в 2–3 раза.
- Профиль поворота за полёт (360° для сальто): открытая фаза 0–20% времени → 10–15% оборота; группировка 20–80% → ~70%; раскрытие 80–100% → оставшиеся 15–20%, вращение замедляется перед приземлением.
- Средняя угловая скорость `360/T`: при полёте 0.65 с ≈ 550°/с = 23°/кадр [18]; пик в группировке 800–900°/с = 35°/кадр → нужен motion blur.
- Приземление на 330–350° (недокрут), докрут до 360° — за счёт поглощения в коленях за 3–5 кадров.

```python
def flip_profile(u, total=360.0, tuck=(0.2, 0.8), share=0.7):
    """u 0..1 доля полёта -> угол. Медленно-быстро-медленно с постоянным ω в каждой фазе."""
    a, b = tuck; s_open = (1 - share)/2
    if u < a:   return total*s_open*u/a
    if u < b:   return total*(s_open + share*(u - a)/(b - a))
    return total*(s_open + share + s_open*(u - b)/(1 - b))
```
Стыки фаз сгладь `blend` на 2–3 кадра, иначе видны изломы угловой скорости.

### 6.4 Вращение предметов
- Предмет вращается вокруг своего ЦМ: пивот геометрии ставь в ЦМ, не в угол.
- Брошенная вытянутая вещь (палка, бутылка) крутится через конец, 1–3 оборота/с; плоская (монета, карта) — вокруг короткой оси с прецессией.
- Вращение на вентиляторе/колесе — равномерное `linear`; разгон за 0.5–1 с `in_pow(2)`, выбег в 2–4 раза дольше разгона `out_pow(2)`.

### 6.5 Передача импульса
- Ударенный предмет получает скорость `≈ v·m1/(m1+m2)·(1+e)`: лёгкий отлетает быстрее бьющего, тяжёлый почти не двигается — бьющий отскакивает.
- Тяжёлый предмет, сбитый лёгким: сдвиг 1–5 см + тряска 2–4 кадра — так продаётся его масса.

### 6.6 Баллистика осколков

```python
def debris(n, fps, seed=1, v=(250, 700), cone=55, spin=(180, 1080), e=0.3, fr=0.6, frames=48):
    """Траектории n осколков из точки (0,0,0) вверх-в-стороны с отскоком от y=0.
    Возвращает список [(x,y,z,rot_deg) по кадрам]. Скорости см/с, spin град/с."""
    random.seed(seed); g = 981.0/fps/fps; out = []
    for _ in range(n):
        sp = random.uniform(*v)/fps
        el = math.radians(90 - random.uniform(0, cone)); az = random.uniform(0, 2*math.pi)
        vx = sp*math.cos(el)*math.cos(az); vz = sp*math.cos(el)*math.sin(az); vy = sp*math.sin(el)
        w = random.uniform(*spin)/fps*random.choice((-1, 1))
        x = y = z = r = 0.0; tr = []
        for _ in range(frames):
            vy -= g; x += vx; y += vy; z += vz; r += w
            if y < 0:
                y = -y*e; vy = -vy*e; vx *= fr; vz *= fr; w *= fr
                if abs(vy) < g*2: y = 0.0; vy = 0.0
            tr.append((x, y, z, r))
        out.append(tr)
    return out
```

Дозировка: крупных осколков мало (3–6) и они медленнее/ниже, мелких много (20–60) и они быстрее/выше; разброс скоростей ×2–3; первые 2–4 кадра — самые быстрые (вспышка рядом, §7.4). Пыль: медленнее, тормозит воздухом `v *= 0.9` за кадр, растёт в размере.

## 7. Импакт

### 7.1 Анатомия удара — кадры 24 [30]

| Фаза | Лёгкий | Средний | Тяжёлый |
|---|---|---|---|
| подготовка | 3–4 [4–5] | 6–8 [8–10] | 12–20 [15–25] |
| удар (до контакта) | 1–2 | 2–3 | 3–5 |
| hit-stop | 2 [2–3] | 3–4 [4–5] | 5–8 [6–10] |
| отдача (recoil) | 3–4 | 4–6 | 6–10 |
| оседание | 6 | 8–12 | 12–24 |

Удар — `in_pow(2..3)`, последний интервал перед контактом самый длинный; **контакт — ключ, а не ease**. Отдача — `out_expo` или `spring ζ0.4–0.6`, амплитуда 5–15% удара в обратную сторону.

### 7.2 Hit-stop
- Замораживание **обоих** (бьющего и цели) на кадре контакта. В файтингах при 60 fps — 7 кадров лёгкий / 11 тяжёлый (≈0.12–0.18 с) → 3–4 [4–5] кадров в ролике; кинематографичный тяжёлый — до 8 [10].
- Во время стопа цель дрожит: смещение ±1–3 см через кадр (чётный +, нечётный −) с затуханием — так стоп не выглядит как зависание рендера.
- Окружение (частицы, камера) может продолжать двигаться — замирают только участники.

### 7.3 Тряска камеры

В 3D тряси **вращением** камеры (позиция при тряске врезается в геометрию и меняет параллакс). Модель «травмы»: `shake = A·trauma²`, trauma 0..1 копится от ударов и спадает линейно за 0.5–1 с.

```python
def shake(t, amp=1.0, freq=12.0, decay=0.25, seed=0.0):
    """Затухающая тряска, t — секунды от удара, amp — градусы. На каждую ось свой seed."""
    if t < 0: return 0.0
    n = math.sin(2*math.pi*freq*t + seed) + 0.5*math.sin(2*math.pi*freq*2.17*t + seed*1.7)
    return amp*math.exp(-t/decay)*n/1.5

def wobble(t, amp=1.0, freq=0.7, seed=0.0):
    """Шум «ручной камеры»: сумма несоизмеримых синусов, без затухания."""
    ks = ((1.0, 1.0), (2.13, 0.45), (3.71, 0.2))
    return amp*sum(w*math.sin(2*math.pi*freq*k*t + seed*(i + 1)*1.3)
                   for i, (k, w) in enumerate(ks))/1.65
```

| Событие | Амплитуда rp/rh | Частота | Затухание τ | Ось |
|---|---|---|---|---|
| шаг гиганта (далеко) | 0.2–0.4° | 5–8 Гц | 0.12 с | в основном rp (вертикаль) |
| шаг гиганта (рядом) | 0.6–1.2° | 4–6 Гц | 0.2 с | rp + слабо rb |
| удар кулаком | 0.3–0.8° | 10–15 Гц | 0.1 с | вдоль удара |
| приземление героя | 0.5–1° | 6–10 Гц | 0.15 с | rp |
| взрыв рядом | 2–4° | 8–12 Гц, затем 2–3 | 0.4–0.6 с | все три, rb слабее |
| землетрясение, гул | 0.2–0.5° | 2–4 Гц | без затухания | wobble |
| ручная камера | 0.1–0.4° + 0.02–0.05° | 0.3–1.5 Гц + 6–10 Гц | — | wobble на rp, rh |

Начало тряски — **на кадре контакта**, первый толчок самый сильный и в сторону удара. Позиционная тряска допустима до 0.5–2 см при широком объективе на открытом пространстве.

### 7.4 Вспышка и кадры импакта
- 1–2 кадра вспышки: скачок интенсивности света ×3–10 или белый/инвертированный кадр (аниме: 1–3 кадра контрастного силуэта), затем 1 кадр промежуточный, затем норма.
- В C4D: ключ интенсивности источника `step`-ключами, или переключение видимости объекта-вспышки `key_vis`; инверсия/цвет — на композе.
- Частота вспышек — не чаще 3 в секунду (фоточувствительная эпилепсия).

### 7.5 Смир и motion blur
- Выдержка = `(угол затвора/360)/fps`: 180° при 24 = 1/48 с (норма кино); 270–360° — размазанно, для быстрых акций; 45–90° — рваный «стаккато» (баталии, нервозность).
- Смир в 3D: на 1–2 кадрах максимальной скорости растягивай объект вдоль скорости ×1.5–3 (сквош-нуль из §1.1) или выводи 2–4 полупрозрачных «призрака» с отставанием по 1/3 кадра.
- Порог: сдвиг > 10–15% кадра за кадр без блюра читается как телепорт.

## 8. Моушн-дизайн и типографика

### 8.1 Стаггер (сдвиг запуска в группе)
- Шаг: по буквам 1 кадр [1–2], по словам 2–3 [3–4], по строкам/карточкам 3–6 [4–8].
- Весь разбег стаггера ≤ 30–50% длительности одного элемента, иначе группа распадается на отдельные события. Общая длина = `длит + (n−1)·шаг`.
- Порядок: по направлению чтения; от точки интереса наружу (центр, место удара); по кругу — для радиальных групп. Случайный порядок — только для «россыпи», с `random.seed`.
- Неравномерный стаггер (первые быстро, последние догоняют) — задержки по кривой: `delay_i = D·ease(i/(n−1))`, `ease = out_pow(t,2)`.
- В C4D: MoGraph — эффектор Step/Delay или поле Linear Field с длинным спадом поверх Cloner; для отдельных объектов — `bake` со сдвигом `f − i·шаг`.

### 8.2 Оверлап
Следующий элемент стартует до окончания предыдущего — перекрытие 30–60%. Без перекрытия анимация звучит как «слайд-шоу»: стоп, старт, стоп.

### 8.3 Правило трёх скоростей
В кадре одновременно три яруса движения, длительности примерно **1 : 2 : 4+**:
1. **Акцент** — главное, быстро (6–12 кадров), сильный ease-out, перелёт;
2. **Поддержка** — вторичные элементы, средне (12–24 кадра), мягче;
3. **Фон/эмбиент** — непрерывный медленный дрейф (поворот 2–5°/с, сдвиг 1–2% кадра/с, f 0.1–0.3 Гц), никогда не замирает полностью.
Всё в одном темпе = монотонность; ни одного медленного яруса = суета.

### 8.4 Вход, уход, маски
- Вход — ease-out (`out_quint`, `out_expo`, M3 emphasized decelerate), уход — ease-in, уход в 0.6–0.8 раза короче входа.
- Текст «из-под маски»: сдвиг по Y на 100–120% высоты строки, 10–16 кадров [12–20], `out_expo`/`out_quint`, плюс поворот 3–8° по наклону строки — живее.
- Масштаб из нуля: `out_back(s=1.2–1.7)` за 8–12 кадров; текст никогда не масштабируй из нуля линейно. Спокойнее: из 0.8–0.9 + прозрачность.
- Прозрачность растёт быстрее движения: opacity 0→1 за первые 40–60% длительности сдвига.
- Морф форм: точки сопоставлены (одинаковое число, порядок обхода), 8–16 кадров `in_out_pow(3)`, на середине самая быстрая фаза — туда допустим блюр; перед морфом сжатие 3–5% (подготовка). В C4D — PoseMorph-тег или запекание сплайнов.

### 8.5 Логотип и типографика: структура реверса
1. **Сборка** 24–48 кадров [30–60]: элементы приходят стаггером, камера медленно наезжает (1–2% масштаба/с).
2. **Хит/замок** 2–6 кадров на сильную долю (§8.6): последний элемент встаёт на место резко, вспышка/свип света, тряска 0.2–0.4°.
3. **Оседание** 8–12 кадров: перелёт 3–8% (`spring ζ0.5–0.7`), не больше — логотип должен «встать».
4. **Холд** ≥ 36–48 кадров [45–60]: читаемо, неподвижно по позиции; живёт свет (свип блика 12–24 кадра) и медленный пуш камеры 2–5% за холд.
5. **Уход** (если нужен) 8–12 кадров ease-in или затемнение.
Итого 3–5 с.

Время чтения текста на экране: `0.5 с + 0.3 с × слов` (≈3 слова/с), минимум 1 с; заголовок из 2–3 слов — 1.5–2 с [36–48 кадров @24].

### 8.6 Ритм под BPM
Кадров на долю = `fps × 60 / BPM`. Позицию n-й доли считай **накопленно**: `round(n·fps·60/BPM)`, а не `n·round(...)` — иначе к 30-й доле уедешь на несколько кадров.

| BPM | 24 fps | 30 fps | 25 fps |
|---|---|---|---|
| 90 | 16.0 | 20.0 | 16.7 |
| 100 | 14.4 | 18.0 | 15.0 |
| 110 | 13.1 | 16.4 | 13.6 |
| 120 | 12.0 | 15.0 | 12.5 |
| 128 | 11.25 | 14.1 | 11.7 |
| 140 | 10.3 | 12.9 | 10.7 |
| 150 | 9.6 | 12.0 | 10.0 |

- Удобные пары (целые кадры): 24 fps — 90, 120, 144, 160 BPM; 30 fps — 90, 100, 120, 150.
- Акцент (контакт, хит логотипа, смена позы) — **на долю**; подготовка начинается за полдоли–долю; самые важные события — на первую долю такта.
- Звук удара — на кадр контакта или +1, никогда раньше картинки.
- Цикл-луп: длина = целое число долей, периоды всех синусов — делители длины лупа.

| **orbit / arc** | облёт вокруг цели | частичный 15–45° за шот; турнтейбл 360° за 8–12 с (30–45°/с при 35 мм, ≤15°/с при 85 мм) | объём продукта, драма |
| **follow / tracking** | едет за объектом | `spring_follow`, halflife 0.1–0.3 с; поле впереди объекта ⅓ кадра | погоня, путь |
| **whip pan** | резкий пан | 90–180° за 4–8 кадров [5–10], блюр 270–360°, склейка в середине | переход, удивление |
| **rack focus** | перевод фокуса | 12–24 кадра [15–30], `in_out_pow(2)`, после мотивации (взгляд, звук) | сменить объект внимания |
| **dolly zoom** | проезд + обратное фокусное | `f(t) = f0·d(t)/d0`, d меняется ×1.5–3 за 2–4 с | головокружение, осознание |
| **handheld** | «ручная» | `wobble`: 0.1–0.4° на 0.3–1.5 Гц + 0.02–0.05° на 6–10 Гц | документальность, нервы |
| **статика** | ноль движения | без дрейфа | наблюдение, комедия, симметрия |

Не больше **двух** компонент одновременно (например, dolly + tilt); три и больше — укачивает.

### 9.3 Ease камеры
- Камера тяжелее всего в кадре: разгон 12–24 кадра [15–30], торможение 24–48 [30–60] — дольше старта.
- Внутри шота камера стартует **после** мотивации (персонаж двинулся → камера через 4–8 кадров), останавливается **после** объекта (+6–12 кадров).
- Лучше войти в шот уже в движении (склейка на середине проезда) — без видимого старта.
- Резкий стоп камеры — только как акцент (удар, испуг) и с тряской.
- `spring_follow` на каждой оси позиции и прицела отдельно; halflife прицела меньше (0.08–0.15 с), чем позиции (0.2–0.4 с) — камера сначала доворачивает, потом доезжает.

### 9.4 Мотивация
Камера движется, потому что: (1) движется объект; (2) надо раскрыть информацию (reveal); (3) меняется эмоциональная дистанция — наезд = близость/напряжение, отъезд = изоляция/итог; (4) это взгляд персонажа. Нет причины — статика. Простое лучше: **общий план + медленный наезд** покрывает 80% задач заставки.

### 9.5 Правила 180° и 30°
- **180°**: камеры одной сцены по одну сторону оси действия (линии между персонажами или вектора движения). Пересёк — направление на экране перевернулось. В пайплайне: герой бежит +X, камеры смотрят ≈ −Z (c4d-core §5). Пересечь можно, показав пересечение в кадре движением камеры.
- **30°**: соседние шоты одного объекта — разница ракурса ≥ 30° и/или масштаба ×1.5–2, иначе склейка читается как скачок (jump cut).
- Направление движения через склейку сохраняется: вышел слева направо → входит слева направо.

### 9.6 Продукт-шот
- Объектив 50–100 мм (без дисторсии), деталь — 100 мм+ с малой глубиной резкости.
- **Hero-ракурс**: камера на 10–20° ниже центра продукта, ¾ (поворот 30–45°), продукт чуть смотрит в камеру.
- **Reveal**: из темноты контровым светом (свет едет 24–48 кадров), из-за переднего плана (truck мимо окклюдера), из расфокуса (rack focus), появление сборкой (§8.5).
- **Облёт**: частичный 20–60° с параллаксом фона медленнее; полный 360° — только турнтейбл.
- **Hero moment**: замедление (ramp скорости до 0.3–0.5), свип блика, финальный пуш 3–5%, холд 1.5–2 с.
- Сверху (flat-lay) — для набора предметов; деталь макро — 1–2 с на кадр, по 2–4 детали между общими.

## 10. Монтаж

| Шот | Длина |
|---|---|
| установочный общий | 3–5 с [72–120 кадров @24] |
| средний/диалог | 2–4 с |
| экшн-фрагмент | 0.5–2 с |
| деталь, вставка | 1–2 с |
| промо/тизер | 0.7–2 с |
| логотип с холдом | 3–5 с |
| вспышка-кадр | < 0.5 с (12 кадров) — только для импакта |

- Средняя длина шота в современном кино 2.5–4 с; заставка 5–15 с = 3–6 шотов.
- Ритм: варьируй длины; к кульминации каждый следующий шот 0.7–0.8 предыдущего, после неё — длинный холд.
- **Склейка на действии**: режь во время движения, не до и не после. Исходящий шот заканчивается через 1–3 кадра после начала действия; входящий повторяет 2–4 кадра того же действия (перекрытие) — склейка исчезает.
- **Match cut**: совпадает форма, движение или цвет; главное — **точка внимания на одном месте кадра** по обе стороны склейки.
- Шторки-переходы: объект переднего плана закрывает кадр, вжик-пан, затемнение через тёмный объект — склейка на кадре полного перекрытия.
- Движение через склейку: «в движении → в движение, статика → статика»; направление и скорость камеры совпадают.
- Склейка — на долю (§8.6).

## 11. Диагностика

| Симптом | Причина | Правка |
|---|---|---|
| **вяло, плавает** | длительности велики; `in_out` на всём; нет холдов; ease в контакт | длительности −20–30%; входы `out_expo`; контакт без ease (`in_pow(2)` → ключ); холды 4–8 кадров; добавить подготовку |
| **дёргается** | автотангенсы перелетают между близкими ключами; разные каналы ключованы на разных кадрах; скачок угла через ±180°; округление позиций; эффект дилижанса | запечь `bake` покадрово `linear`; развернуть углы; проверить вторые разности (ниже); блюр на быстром вращении |
| **мультяшно** | перелёт > 10% у тяжёлого; сквош у твёрдого; время не масштабировано по размеру | перелёт ≤ 3–5%; убрать сквош, дать отдачу и тряску; время × `sqrt(размер)` (§2.4) |
| **желе** | много пружин с ζ < 0.3; одинаковые частоты; качание дольше 1.5 с; качается родитель | ζ 0.5–0.7; f дочерних ×1.5–2; затухание ≤ 0.5–1 с; пружинит максимум 1–2 элемента |
| **роботом** | равный спейсинг; все каналы стартуют на одном кадре; симметрия; прямые пути | сдвиг каналов 1–3 кадра; асимметричный ease; дуги; амплитуды L/R ±10–20% |
| **не читается** | действие < 4 кадров без подготовки и холда; на камеру; одновременно с другим | подготовка + холд 6–8 кадров; поперёк оси камеры; развести по времени |
| **нет веса** | мгновенный старт; остановка «на ключ»; окружение не реагирует | §4.2: разгон ×2, перелёт корпуса, тряска/пыль |
| **укачивает** | камера движется по 3+ осям; средняя скорость пана; нет мотивации | 1–2 компоненты; скорость по §9.1; статика |
| **телепорт** | сдвиг > 10–15% кадра за кадр | motion blur 180–270°, смир, больше кадров |

### 11.1 Численная проверка кривой

```python
def check(vals, lo=None, hi=None, fps=24):
    """vals — значения канала по кадрам. Ищет рывки, перелёты, скачки углов."""
    v = [vals[i+1] - vals[i] for i in range(len(vals) - 1)]
    a = [v[i+1] - v[i] for i in range(len(v) - 1)]
    med = sorted(abs(x) for x in a)[len(a)//2] or 1e-6
    rep = {"vmax_per_frame": max(abs(x) for x in v),
           "jerks": [i + 1 for i, x in enumerate(a) if abs(x) > 4*med and abs(x) > 1e-3],
           "angle_jumps": [i for i, x in enumerate(v) if abs(x) > 180]}
    if lo is not None: rep["undershoot"] = min(vals) < lo
    if hi is not None: rep["overshoot"] = max(vals) > hi
    return rep
```

Значения канала по кадрам снимай через `doc.SetTime` + `ExecutePasses` (как `at(f)` в modes/animator.md). Рывки на кадрах ключей — норма для удара и контакта, в остальных местах — дефект.
